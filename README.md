# PolyFullBright

PolyFullBright lights up the whole world, so caves and nights are never dark. It only changes what you see, and mobs still spawn like they normally would.

- Choose how bright things get with a light level slider
- Goes brighter than vanilla's Brightness setting allows on modern versions
- Works with the Argentum renderer on 1.8.9

## Supported versions

- Minecraft 1.8.9 on Ornithe.
- Minecraft 1.21.1-26.3 on Fabric.

PolyFullBright needs [OneConfig](https://modrinth.com/mod/oneconfig) and Fabric Language Kotlin.
